02/06
The Loop

Four roles, four perspectives,
zero self-review.

Design
01

Clarify requirements, constraints, risks, and acceptance criteria.
The Designer never writes code.

Code
02

Implement from spec. Can't see Reviewer feedback. Never self-approves.

Review
03

Adversarial review: scope creep? Design drift? Missing error handling?

Test
04

Verify against pre-written criteria. Leave auditable evidence. Never trust the Coder's word.

Design → Code → Review → Test → Deep Review → Done
Review or Test fails? Automatically enters the amending loop.
Humans gate at the final Accept phase, not at every step.
One feature, four separate responsibilities. 4x run --runner claude

04/06
Safety

Safety is enforced in Go,
not in prompts.

Don't rely on AI self-discipline. The CLI hard-enforces every boundary.

State Machine init → designing → coding → reviewing → testing → done. No skipping allowed.
Scope Lock Changed files must be within declared repos scope. Out of bounds = blocked.
Baseline Snapshot Snapshot before coding. Rollback to clean state anytime.
Evidence Gate Tester must produce verify.json + test-report. No evidence, no pass.
Dependency Gate Prerequisite feature not done? This feature can't start.
Human Gate After all AI phases complete, pending-review waits for human final approval.
Crash Recovery + Transient Retry Runner crashes auto-recover. Transient API errors auto-backoff retry.
A network hiccup won't destroy your entire batch run.
AI handles judgment, CLI enforces boundaries. .4x/ protocol

Self-Evolution

4x learns from
its own failures.

L1
Retro Learnings Post-round retrospectives auto-tune next round's prompt templates. Gets better with every run.
L2
History Mining Extracts improvement signals from failed runs, escalations, and recurring FAIL patterns.
L3
Feature Enrichment Auto-discovered improvements get subtasks, scope, and priority filled in, then queued into the pipeline.
L4
Value Gate + Scope Guard ROI evaluation + anti-hack protection. Extra safeguards when modifying its own core.
L5
Evolve Driver One command to start the continuous self-improvement loop: mine → evaluate → implement → verify → deploy.
AI doesn't just execute engineering workflows — it learns from its own failures, iterates continuously, and gets stronger with every run.
