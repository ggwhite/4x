DCT Live vs 4x Live — 風格差異分析

以下是兩者的主要視覺差異，點選你認為最需要優先改進的項目

1

Sidebar 分組視覺

DCT Live 的 section header 更明顯（粗體大寫 + 計數 badge），卡片有彩色邊框和 badge（B1/4 綠、A1/3 橘）。4x Live 的 section header 太輕，卡片缺少視覺區分。

2

角色標籤與 Emoji

DCT Live 每個角色有 emoji（🎨 Designer、⊙ Reviewer）和鮮明配色。4x Live 有顏色但沒有 emoji，標籤較不醒目。

3

背景色調與質感

DCT Live 用深藍綠色調（類似 Frost），有微妙的漸層和 glass 質感。4x Live 預設純黑 #0f0f0f，Frost 主題雖有藍調但缺乏漸層層次。

4

驗證狀態 Badge

DCT Live 在 header 有彩色 badge 行（review、R9、scope、build ✓、test ✓、vet ✓、smokeCheck ✓）。4x Live 只有簡單的 phase + round 文字。

5

程式碼區塊與 Markdown

DCT Live 的 code block 有更深的背景、更好的間距。4x Live 的 markdown 渲染偏素。

6

整體 Native App 感

DCT Live 有 vibrancy/blur 效果、圓角更統一、間距更舒適。4x Live 像是「開發者寫的 UI」，缺少設計感的打磨。
